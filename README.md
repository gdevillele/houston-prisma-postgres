# Houston connector for Prisma Postgres

A [Houston](https://ok-houston.com) connector that gives agents SQL access to a
[Prisma Postgres](https://www.prisma.io/postgres) database, read-only unless you
allow changes.

The bundle lives in [`connectors/prisma-postgres`](connectors/prisma-postgres).
It follows the [houston-hub authoring guide](https://github.com/aibakery/houston-hub/blob/main/AUTHORING.md).
Publish it in [Houston Hub](https://hub.ok-houston.com) under **My connectors**
with this repository, the `main` branch and the `connectors/prisma-postgres` folder.
